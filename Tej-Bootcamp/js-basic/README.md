//Value in JavaScript -

- value is a piece of data that can be stored, retrieved and manipulated in a program. Every value has a type, which determines how it can be used and what operations can be performed on it.
  // Value Types in JavaScript
- A type tells JavaScript what kind of value it is.
- It can be a number, a string, a boolean, an object, or any other type of data.there are several primitive value types, including:
- Number: Represents numeric values, such as 42 or 3.14.
- String: Represents sequences of characters, such as "Hello, World!" or 'JavaScript'
- Boolean: Represents logical values, either true or false.
- Null: Represents the absence of any value.
- Undefined: Represents a variable that has been declared but has not been assigned a value.
